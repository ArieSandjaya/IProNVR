IproD3D - modul Wall Direct3D (opsional)

Dekode D3D11VA (ffmpeg in-process, FFmpeg.AutoGen 9.0.1.1) + render Direct3D 11 (SharpDX 4.2.0).
Dimuat IproNvrTool lewat reflection (D3dWall.cs). Menu: Wall Direct3D (dekode GPU, uji coba).

DLL ffmpeg 9.0 shared (wajib, versi harus avcodec-63):
  https://github.com/BtbN/FFmpeg-Builds/releases/download/latest/ffmpeg-n9.0-latest-win64-gpl-shared-9.0.zip
  Salin SEMUA .dll dari folder bin di zip ke folder ffmpeg9 di samping IproNvrTool.exe
  (atau isi foldernya di Setup > Dekode & stream).

Di jendela: Esc = tutup, klik dua kali = perbesar satu kamera (stream utama) / kembali, I = info frame.
Zoom digital (semua kamera): roda mouse = zoom in/out, tarik dengan mouse = geser, klik kanan atau tombol 0 = kembali 1x.
PTZ optik: Ctrl + roda, atau PgUp/PgDn, + / -; panah = geser kamera PTZ.
